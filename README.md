# multimodal-llm-server
マルチモーダルなAIとのチャットをするためのバックエンドサーバ

## 起動

```bash
./run-server.sh
```

既定では `0.0.0.0:13443` で HTTPS サーバ、`0.0.0.0:13080` で HTTP サーバを起動します。
自己署名証明書は `.local/tls/localhost.p12` に自動生成されます。

HTTPは `127.0.0.1` または `::1` からの接続だけを通常処理します。それ以外の接続は、同じホスト、パス、クエリを維持したままHTTPSの `13443` ポートへ `308 Permanent Redirect` で転送します。

```bash
./run-server.sh 113443 0.0.0.0 13080
```

第1引数で HTTPS ポート、第2引数で待受アドレス、第3引数で HTTP ポートを指定できます。
